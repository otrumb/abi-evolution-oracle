# ABI Evolution Oracle v0.1.0

First experimental release of a local CLI that reports consumer compatibility evidence for a frozen 50-case Ethereum ABI corpus and pinned consumer versions.

Included evidence covers directional result decoding, generated Go client compatibility, event filter and decode behavior, collision ambiguity, and structural controls. Linux amd64 and Windows amd64 archives include the CLI, MIT license, and README.

## Scope limits

Runtime behavior, storage compatibility, and security were not assessed. Deployment compatibility is unknown. Demand and adoption are unvalidated. Results apply only to the checked-in corpus, consumers, versions, and configurations.

The release does not provide a universal compatibility, safety, or contract-upgrade verdict.
